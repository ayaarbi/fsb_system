Pour démarrer le serveur, tapper
```
python manage.py runserver
```
Vous pouvez utiliser les identifiants 'admin' et 'admin123' comme identifiants d’utilisateur et mot de passe lors de l’authentification. 
Normalement la base est enregistrée dans le fichier fsb_database.db, on a utilisé SQLite mais je crois que l'utilisation d'un SGBD comme Postgres sera mieux.
Pour les agents IA, ils ne sont pas actifs (nécessitent des api keys je crois)
